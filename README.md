# Lilanga Gallery
Avvio: `npm install` poi `npm start` → http://localhost:3000

- Parola d'ordine iniziale del sito: `shetani` (modificabile in Admin → Contenuti)
- Admin: http://localhost:3000/admin — password iniziale `lilanga-admin` (o variabile `ADMIN_PASSWORD` al primo avvio). Cambiarla subito.
- Dati in `data/db.json`, immagini in `data/uploads/` (fare backup di `data/`).
